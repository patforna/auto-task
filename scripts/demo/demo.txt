# auto-task demo screenplay.  Render with ./render.sh  ·  full reference: cast.py
#
# Plain lines print verbatim (blank lines and indentation included).
# "#" at column 0 is a comment; an indented "#" is content, so markdown survives.
# Styling: {bold} {dim} {orange} {green} {cyan} {yellow}, each closed by {/}
#
# The numbers are NOT all durations:
#
#   @prompt <text>          a human types it, then enter.  Takes NO number.
#                           A leading /command is bolded, its arguments are not.
#   @step <secs> a|b|c      a line with a braille spinner, revealed chunk by
#                           chunk.  <secs> is PER CHUNK, not total (±CHUNK_JITTER).
#                           Resolves to a green tick.
#   @step! <secs> a|b       the same, but left SPINNING until an @resolve. Use it
#                           when the step is genuinely blocked on the human.
#   @resolve <secs>         finish the pending @step! in place.  <secs> is the
#                           beat before the tick lands.  One pending step at a time.
#   @ask <text>             a question handed back to you.
#   @select <n> a|b         a TUI picker.  <n> is the 1-BASED OPTION chosen,
#                           not a duration.  Timings live in cast.py (SELECT_*).
#   @pause <secs>           wait, showing nothing new.
#   @clear                  wipe the screen and start again at the top.
#
# Blank lines never double up.  The last frame is always held for END_PAUSE.
# Lines wider than COLS (80) print a warning on render.

@pause 0.4
