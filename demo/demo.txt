# auto-task demo screenplay.  Render with ./render.sh  ·  directives and full reference: cast.py
#
# Plain lines print verbatim (blank lines and indentation included).
# "#" at column 0 is a comment; an indented "#" is content, so markdown survives.
# Styling: {bold} {dim} {orange} {green} {cyan} {yellow} {red} and the phase-row
# greys {pending} {clock} {sep}, each closed by {/}.  {bold} sets the weight AND
# returns to the default foreground, which is what lifts a count out of the grey
# around it.  {/} pops to the enclosing tag, so "{bold}4{/} ACs" in a gloss or an
# @detail leaves "ACs" grey.  A brace-wrapped word that isn't a tag warns on render.
#
# Every phase row sits on one grid: glyph cols 1-2, label 3-19, gloss 20-55, clock
# at 56.  Write labels BARE — the renderer bolds them, appends "..." while the row
# runs and drops it when it lands.  The label width is only there to line a gloss
# up, so a row with neither gloss nor clock lets its label run on — that is how a
# heading is written.  "·" tints itself inside a gloss and inside an @detail; on any
# other line write it {sep}·{/} yourself.
#
# The numbers are NOT all durations:
#
#   @prompt <text>          a human types it, then enter.  Takes NO number.
#                           A leading /command is bolded, its arguments are not.
#   @step <secs> <l>|<g>    a phase row that spins for <secs> — the whole row,
#                           ±HOLD_JITTER — then ticks over to done in place.
#   @step! <secs> <l>|<g>   the same, but left SPINNING until an @resolve.  Use it
#                           when the step is genuinely blocked on the human.
#   @resolve <secs>         finish the pending @step! in place, however far the
#                           cursor has moved on.  <secs> is the beat before the
#                           tick lands.  One pending step at a time.
#   @checklist <a>|<b>|<c>  print every phase up front, all pending, so the shape
#                           of the run is on screen before any of it happens.
#   @run <secs> <l>|<g>|<clock>
#   @run <secs> <l>|<running g>|<done g>|<clock>
#                           tick one checklist row over: it spins for <secs>, then
#                           lands.  Rows must run in the order they were listed.
#                           <clock> is how long THAT row took, M:SS — it counts up
#                           from 0:00 to it.  Four fields swap the gloss on landing.
#   @row <glyph> <l>|<g>    one finished phase row, printed as-is: no spinner, no
#                           tick, no "...".  Takes NO number; a third field adds
#                           a clock.  With no gloss at all, it is a heading.
#   @detail <text>          a line under a heading: indented to col 3, in the gloss
#                           grey, separators tinted for you.  Takes NO number.
#   @ask <text>             a question handed back to you.
#   @select <n> a|b         a TUI picker.  <n> is the 1-BASED OPTION chosen,
#                           not a duration.  Timings live in cast.py (SELECT_*).
#   @pause <secs>           wait, showing nothing new.
#   @clear                  wipe the screen and start again at the top.
#
# Blank lines never double up.  The last frame is always held for END_PAUSE.
# A label past 17 cells, a gloss past its column or a line past 80 warns on render.
#
# Every count below is from one real run bar `1 flag` — README.md § Provenance has the
# receipts.
# Change one only with evidence, and keep the two screens agreeing: the phase
# clocks sum to the signoff block's 9m 20s.

@prompt /at:create-task build a hello-world cli that greets by name. TS + bun.
@step! 1.2 Clarifying|read repo · find ambiguities

@ask What if no name is given?
@select 2 hello → usage, exit 1|hello → Hello, World
@resolve 0.35

@step 1.5 Creating task|intent · ACs · notes
@step 1.1 Tightening|{bold}3{/} lines cut

@row {green}✓{/} Task 001 ready for dev
@detail tasks/001-hello-world-cli.md · {bold}4{/} ACs
@pause 1.5

# A typed command before the wipe, so the mid-clip clear can't be mistaken for the
# loop restarting: both go full screen -> blank -> a prompt types out, and only this
# one has a beat in front of it.  /clear is also what you would really do here —
# the task file carries the state, so the build starts on fresh context.
@prompt /clear
@pause 0.35
@clear
@prompt /at:auto-task 001
